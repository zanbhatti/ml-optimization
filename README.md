# ML Optimization

A collection of research and engineering projects exploring model optimization, efficient inference, and the relationship between computational efficiency and model capability.

## Projects

### [Quantized Reasoning](./quantized-reasoning)

An empirical study investigating whether post-training quantization disproportionately degrades language-model reasoning as required reasoning depth increases.

**Current focus:** Controlled evaluation of Qwen3 4B across BF16, 8-bit, and 4-bit precision using reasoning-depth annotations from ProofWriter.

**Stack:** Python · MLX · Hugging Face · LLM Evaluation
